# Sobia Fayyaz: Responsive Portfolio Web Application

> **Task 2 · Full Stack Development Internship · Progree**  
> A semantic, fully responsive single-page portfolio website built with pure HTML5, CSS3, and Vanilla JavaScript.

## Project Overview

This project is a **single-page visual portfolio website** that showcases the professional profile of **Sobia Fayyaz** — a Junior SQA Engineer and Full Stack Developer. The application was built as part of **Task 2** of the Progree Full Stack Development Internship.

The site demonstrates:

- Semantic HTML5 structure
- Custom CSS Grid & Flexbox layout systems
- Fully fluid responsiveness across all screen widths
- Smooth, interactive mobile navigation menu
- Modern, clean, and accessible UI


## Task Requirements (Progree Internship)

| Requirement | Status |
| Build structural blocks using **semantic HTML5** 
| Custom **CSS Grid / Flexbox** systems 
| Ensure **layout fluidity** across all screen widths 
| Implement **CSS media queries** for responsiveness 
| Smooth, **interactive mobile navigation** menu 
| Single-page visual portal profile website 

## Features

- **Modern Card-Based UI** : Soft shadows, rounded corners, and a professional color palette
- **Mobile-First Responsive Design** : Fluid layouts at every breakpoint (800px, 600px, 380px)
- **Interactive Hamburger Menu** : Smooth slide-in navigation on mobile devices
- **Scroll-Based Active Nav Highlight** : Nav links auto-highlight the current section
- **Zero Dependencies** : No frameworks, no build step, no npm install required
- **Accessibility-Friendly** : Proper `aria-label`, `aria-expanded`, and semantic landmarks
- **Font Awesome Icons** : Loaded via CDN for visual polish
- **Clickable Contact Links** : Email, phone, and LinkedIn are all interactive
